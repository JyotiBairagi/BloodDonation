# 🩸 Blood Bank Management System

## 📌 Overview

The **Blood Bank Management System** is a Java-based application designed to manage blood donor and recipient information efficiently. It helps in quick access to blood availability, maintains donor records, and improves response time during emergencies.

---

## 🎯 Features

* Donor Registration
* Recipient Management
* Search Blood by Group & Location
* Donation History Tracking
* Donor Eligibility Check
* CRUD Operations (Create, Read, Update, Delete)

---

## 🛠️ Technologies Used

* **Frontend:** Java Swing (GUI)
* **Backend:** Core Java / Advanced Java
* **Database:** MySQL
* **Connectivity:** JDBC (Java Database Connectivity)

---

## 🏗️ System Architecture

The project follows a **three-tier architecture**:

1. **Presentation Layer (Frontend)**

   * Developed using Java Swing
   * Handles user interaction

2. **Application Layer (Backend)**

   * Implemented using Java
   * Contains business logic

3. **Data Layer (Database)**

   * MySQL database
   * Stores donor and recipient data

---

## 🔗 Working Flow

1. User enters data through GUI
2. Java backend processes the request
3. JDBC connects to MySQL database
4. Data is stored/retrieved
5. Results are displayed on the screen

---

## 📊 Modules

* Donor Module
* Recipient Module
* Search Module
* Database Management Module

---

## ⚙️ Installation & Setup

1. Install **Java JDK (17 or above)**
2. Install **MySQL Server**
3. Clone this repository:

   ```bash
   git clone https://github.com/your-username/blood-bank-management-system.git
   ```
4. Import project into **NetBeans/Eclipse**
5. Configure database connection in JDBC
6. Run the project
